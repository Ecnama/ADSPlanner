# ADS-Planner - Documentation Utilisateur

ADS-Planner est une application ayant pour but de répartir les étudiants de 2STPI dans des sessions ADS après qu'ils aient répondu à un sondage Moodle.

Cette documentation utilisateur a pour but de détailler son utilisation du point de vue de quelqu'un n'étant pas familier avec le code.
